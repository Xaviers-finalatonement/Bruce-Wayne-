# Studio

Short educational science films for five channels, plus a private studio app for review and hand-off.

| # | Channel | Subject |
|---|---|---|
| 1 | Reality Rulebook | physics and how reality works |
| 2 | One More Orbit | space |
| 3 | Possibility Lab | "what if" questions |
| 4 | Body Backstage | the human body |
| 5 | Skin Sense | skin science (education, not medical advice) |

- `docs/style/channels/` — one style sheet per channel
- `docs/style/studio.md` — quality gate, word rules, fact rules
- `docs/style/preview.html` — visual preview of all five looks
- `assets/fonts/` — self-hosted OFL fonts (licences alongside)

Nothing here is posted automatically. Publishing is manual and needs the owner's approval.
